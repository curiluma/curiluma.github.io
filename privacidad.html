Política de privacidad

Última actualización: 14 de noviembre de 2026.

Esta política describe el uso de la web informativa de Curiluma y la automatización privada utilizada para publicar vídeos en su canal de YouTube.

1. Responsable y contacto

Proyecto: Curiluma. Para consultas sobre datos y el funcionamiento de la herramienta, contacta a través de curilumacontacto@gmail.com.

2. Finalidad y datos tratados

La herramienta utiliza la autorización OAuth de Google del titular del canal para publicar vídeos mediante la API de YouTube, consultar el resultado de las subidas y diagnosticar errores técnicos de publicación. Para ello puede procesar identificadores de vídeos, estados de subida y registros técnicos de las operaciones autorizadas.

3. Permisos de Google

La publicación de vídeos mediante la API de YouTube requiere permisos OAuth, habitualmente https://www.googleapis.com/auth/youtube.upload. Los permisos concretos solicitados por la aplicación se muestran al titular en la pantalla de consentimiento de Google.

4. Credenciales, almacenamiento y conservación

La herramienta puede conservar localmente las credenciales necesarias para renovar autorizaciones y los registros técnicos asociados a la generación y publicación de vídeos. El acceso a esta información debe estar restringido a la persona administradora; las credenciales no se publican en esta web. Los registros y credenciales se conservarán únicamente mientras sean necesarios para la operación y el diagnóstico del sistema o hasta que se revoque el acceso.

5. Comunicación con terceros

La herramienta envía a las API de Google/YouTube la información necesaria para publicar vídeos y comprobar sus resultados. Curiluma no utiliza este acceso para vender datos personales ni mostrar publicidad personalizada. El tratamiento realizado directamente por Google se rige por sus políticas.

6. Control, revocación y solicitudes

El titular del canal puede revocar el acceso OAuth desde las conexiones de su cuenta de Google. Para solicitar información o eliminación de datos asociados a la herramienta, puede escribir al contacto indicado arriba.

7. Sitio web

Este sitio es informativo y no requiere iniciar sesión. Su alojamiento en GitHub Pages puede implicar registros técnicos de acceso gestionados por el proveedor de alojamiento conforme a sus propias políticas.

8. Políticas de Google y YouTube

El uso del servicio está sujeto a los Términos del Servicio de YouTube y a la Política de privacidad de Google.
